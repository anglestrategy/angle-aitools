Use the `studying-comparable-launches` skill.

## Inputs to gather

- The category of the project (park, museum, residential, product, cultural institution, etc.).
- Any reference projects the user already has in mind.
- The client's design system.
- Optional: photos or asset folders for each reference.

## Workflow

1. **Pick five to eight references.** Each one should demonstrate a different communication move. Variety beats density. If the user already has a list, work from it. Otherwise propose a shortlist and let the user adjust.
2. **For each reference, research and write two short paragraphs:**
   - *How they positioned it* — what the launch communication actually said and how it framed the project.
   - *What we take from it* — the one move worth borrowing, written as a takeaway for the creative team.
3. **End with a pattern observation** — one paragraph naming what connects the references.

## Output

`[Client] - Comparable Launches.html` in the project folder.

A self-contained HTML page with:

- Sticky nav listing each reference.
- One section per reference: opener with name + city, the two paragraphs, optional images.
- A closing "pattern underneath" panel.

## After writing

1. Run prose through `cutting-the-AI-out-of-the-prose`. Cut all em dashes.
2. Verify image references if used.
3. Present the file with a short summary.

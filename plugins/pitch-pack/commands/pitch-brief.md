Use the `writing-the-creative-brief` skill.

## Inputs to gather

- The brief, RFP, and any supporting documents.
- The client's design system reference.
- The client and project name for the output filename.
- Optional: photos, renderings, diagrams of the project.

## Output

`[Client] - Creative Brief Hub.html` in the project folder.

A self-contained HTML page with:

- Sticky nav.
- Cover.
- Scoreboard section (what the pitch is being judged on).
- The brief table (eleven rows or thereabouts).
- Context panels.
- Anatomy section (with diagram if available).
- Facilities or features list.
- Comparable launches summary (linking out to the full deep-dive if produced).
- Phases / rollout calendar.
- The cornerstone (single strategic note, headline + two columns).

## After writing

1. Run prose through `cutting-the-AI-out-of-the-prose`.
2. Verify all image references resolve.
3. Open in a browser and scroll through.
4. Present the file with a short summary.

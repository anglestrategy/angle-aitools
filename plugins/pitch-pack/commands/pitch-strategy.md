Use the `writing-the-strategy-approach` skill.

## Inputs to gather

- The brief or supporting strategy notes (read these first).
- The client's design system reference (see `porting-a-client-design-system` if not already loaded).
- The client and project name for the output filename.

## Output

`[Client] - Strategy Approach.html` in the project folder.

A self-contained HTML page with:

- Sticky nav listing the ten sections.
- Cover slide with title, strapline, and top/bottom hairlines.
- Ten section openers (giant green section number, title, deck text).
- Multiple panels per section, one idea per panel (see panel-rhythm reference).
- Section seven: comparable launches reads (use `studying-comparable-launches`).
- Footer with handoff to the creative approach.

## After writing

1. Run the prose through `cutting-the-AI-out-of-the-prose`.
2. Open the HTML in a browser and scroll through. Check the panel rhythm (one idea per scroll-height).
3. If the user wants an editable deck on top, run `/pitch-deck` to export.
4. Present the file with a short summary.

# Words and patterns to cut

A working list. Add to it as you discover more.

## Words to avoid

| AI word                  | Plain replacement                            |
|--------------------------|----------------------------------------------|
| intake                   | first read, reading the brief                |
| diagnosis                | what is actually going on                    |
| frame                    | the work the platform has to do              |
| reads (as in "the reads")| readings, takes, lessons                     |
| guardrails               | what to avoid, things to stay away from      |
| handoff                  | passing it to the team                       |
| north star               | the goal, the aim                            |
| lighthouse               | the example, the reference                   |
| unlock                   | open up, enable, make possible               |
| leverage                 | use                                          |
| double down              | commit further                               |
| peer document            | a document the client recognises as theirs   |
| surface area             | the size of the thing, the scope             |
| signal                   | sign, evidence, hint                         |
| lean in                  | go further, commit                           |
| sit underneath           | underneath, under                            |
| portability              | scaling, working in other places             |
| atmosphere               | feel, mood (if "atmosphere" feels forced)    |
| editorial position       | a point of view the brand can publish from   |

## Patterns to avoid

### "X is not Y. It is Z."

Two-sentence definition-by-negation. Strong once per section. Anywhere else, fold into a longer sentence.

### "Not X. Not Y. Z."

Triple negation. Reads as a thinkpiece. Cut.

### "X. Y. Z." (triadic)

Three short noun phrases as a sentence. Pick one.

### "A X that does Y, and Z, and W, and..."

The "infinite list of qualities" sentence. Pick the two that actually matter.

### "From X to Y."

"From a place to a destination." This is a real client phrase in the Waha brief, so it stays in that work. As a default pattern, avoid — it is a strategy-deck cliché.

### "The work the work refuses to be."

The self-referential headline. Cut. Use "What to avoid" instead.

### "X is a Y, not a Z."

The reframe sentence. Use sparingly.

## Punctuation to cut

- Em dash (—) used as a rhythm pause. Replace with period, comma, parentheses, or semicolon.
- Triple-dot ellipses used to imply depth. Cut entirely.
- Bold-text-mid-sentence-for-emphasis. Cut, or use a separate sentence.

## What to keep

- Clear short sentences. Not every short sentence is AI.
- Statements with a single bold idea. Use one per section.
- Direct quotes from clients or research.
- Industry-standard phrases the client uses themselves.

## When in doubt

Read the sentence to a non-strategist friend. If they ask what it means, rewrite it.

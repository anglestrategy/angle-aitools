# Tokens to extract from a client brand brain

A checklist. Work through it in order on every new project.

## Typography

- [ ] Font family name (exact, as installed on the system)
- [ ] Weights in use (Light / Regular / Medium / Bold)
- [ ] Default weight for body text
- [ ] Weight used for emphasis
- [ ] Whether italic is allowed
- [ ] Letter-spacing rules (any negative tracking on headlines? any positive on kickers?)
- [ ] Numerals — lining or old-style?
- [ ] Arabic or other-script equivalents if the brand is multilingual

## Colour

- [ ] Primary surface colour (hex)
- [ ] Secondary surface colour (hex, usually dark)
- [ ] Tertiary surface if any (hex)
- [ ] Accent colour (hex, the one used sparingly)
- [ ] Where the accent is used (text runs, structural elements, both, neither)
- [ ] Where the accent is forbidden (large fills, photographs, decorative backgrounds)
- [ ] Greyscale steps if the system has them

## Layout

- [ ] Horizontal padding (as % of slide width, ideally in cqi)
- [ ] Vertical padding (as % of slide width, ideally in cqi)
- [ ] Slide ratio (16:9 / 16:10 / 4:3)
- [ ] Slide pixel dimensions (1920×1080 by default)

## Hairlines

- [ ] Weight (often 2pt)
- [ ] Colour (usually black on light, white on dark)
- [ ] Y-positions on cover layouts (as % of slide height)
- [ ] Y-positions on divider layouts
- [ ] Y-positions on content layouts
- [ ] Whether they go full-bleed or stop at the padding

## Hierarchy

- [ ] Cover title size
- [ ] Section title / headline size
- [ ] Statement size (the big-type quotes)
- [ ] Card heading size
- [ ] Lead / deck size
- [ ] Body size
- [ ] Kicker / label size
- [ ] Section number size (the big numerals on dividers)

## Components

- [ ] Cover layout pattern
- [ ] Divider layout pattern (label band → number → title → deck)
- [ ] Content layout patterns (single panel, two cards, three columns)
- [ ] Footer pattern

## The non-tokens

Also note things the system actively avoids. Some examples from strong systems:

- "Never use drop shadows."
- "Never use gradient fills."
- "Never use accent colour on photographs."
- "Never centre body text."
- "Never use more than two type weights on a page."

These are as important as the positive tokens.

## Output

Write up all of the above as a single page in the project folder. Reference it from the HTML and PPTX builders.
